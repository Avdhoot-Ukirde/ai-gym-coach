// EXERCISE TRACKING

Train with
real-time feedback

Select an exercise, set a target, and use your camera to track movement and repetitions.

01 / LOWER BODY

Squats

Rep counting from knee-angle transitions, with knee and back-angle indicators.

02 / UPPER BODY

Push-ups

Elbow-angle repetition counting with body-alignment and hip-position estimates.

03 / ARMS

Biceps curls

Tracks elbow movement and provides shoulder-stability and torso-swing indicators.

04 / SHOULDERS

Shoulder press

Tracks elbow extension and estimates back-arch position during the press.

05 / LOWER BODY

Lunges

Counts lunge repetitions and displays front-knee angle, torso angle and balance estimate.

06 / WORKOUT LOG

Session history

Stores completed exercise sets, repetitions and duration in a local SQLite database.

// GET STARTED

Run it
on your machine

Use Python 3.11, install the project dependencies, then start Streamlit from the Main App directory.

Windows PowerShell

cd "Main App"
py -3.11 -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
streamlit run main.py

A webcam and browser camera permission are required. See the repository README for full setup, optional Groq configuration, deployment instructions, and troubleshooting.
